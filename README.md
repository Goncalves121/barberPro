## 🗂️ Estrutura do banco de dados

O sistema conta com 5 tabelas relacionais:
- `[nome_tabela_1]` – [descrição breve]
- `[nome_tabela_2]` – [descrição breve]
- `[nome_tabela_3]` – [descrição breve]
- `[nome_tabela_4]` – [descrição breve]
- `[nome_tabela_5]` – [descrição breve]

> O banco possui lógica de auto-setup, criando as tabelas automaticamente na primeira execução.

## ⚙️ Como executar o projeto

1. Instale o [XAMPP](https://www.apachefriends.org/)
2. Clone este repositório dentro da pasta `htdocs`:
```bash
   git clone https://github.com/Goncalves121/barbershop.git
```
3. Inicie o Apache e o MySQL no painel do XAMPP
4. Acesse `http://localhost/barbershop` no navegador
5. O banco de dados será criado automaticamente na primeira execução
